Stenella is a cross platform open source data platform which integrates a message box that creates article like elements on an interface. The interface is built using Fyne, the go package for cross platform UI and should have build options for linux desktop, android, ios and web. Stenella should allow for data sources to be locally added and pulled from the internet as cards, we should be able to add more cards to the system on their own, the cards should generate a summary and details element based on a title generated. Each card should allow for another card to be linked below it and shown visually. The data should be locally stored in xml files which can be synced.
